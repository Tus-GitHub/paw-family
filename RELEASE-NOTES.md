Paw Family's first public Windows preview.

- One colored kitten per project, with unassigned chats in Others.
- Transparent circular project menu, readable chat list and single-click navigation.
- Original cat/dog artwork, walking, raised-paw alerts, completion animation and custom GIF import.
- Portable, self-contained Windows x64 EXE. No separate .NET runtime or Paw Family account is needed.

Download the Windows ZIP, extract it, then run `PawFamily.exe`. Right-click the pet to exit. No automatic startup is installed.

This is an unsigned preview for local Codex sessions. Some approvals are not exposed in local files, and window reuse can vary by Codex version. The app never approves requests for you. See the README for supported events and limitations.
